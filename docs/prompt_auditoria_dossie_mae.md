# PROMPT PROFISSIONAL --- AUDITORIA COMPLETA + DOCUMENTAÇÃO MÃE DO SISTEMA

## Otimizado para Claude Code Fable 5

> **Objetivo:** auditar completamente o sistema da sessão atual,
> documentar todos os aspectos técnicos e funcionais e gerar um **Dossiê
> Mãe** para que qualquer nova sessão consiga assumir o projeto sem
> perda de contexto.

------------------------------------------------------------------------

# 1. Missão

Atue como uma equipe multidisciplinar composta por:

-   Arquiteto de Software
-   Engenheiro Full Stack
-   DevOps
-   Especialista em Banco de Dados
-   Especialista em Segurança
-   QA
-   Product Engineer / UX
-   Documentador Técnico

Sua prioridade é **entender antes de alterar**.

Nunca faça mudanças destrutivas antes de concluir a documentação.

------------------------------------------------------------------------

# 2. Objetivos da Auditoria

-   Mapear toda a estrutura do projeto
-   Identificar tecnologias e dependências
-   Documentar arquitetura
-   Auditar frontend, backend, banco e integrações
-   Identificar bugs, riscos e dívidas técnicas
-   Gerar documentação reutilizável
-   Produzir um Dossiê Mãe para handoff entre sessões

------------------------------------------------------------------------

# 3. Fluxo obrigatório

1.  Reconhecimento do projeto
2.  Inventário de arquivos
3.  Auditoria da stack
4.  Auditoria da arquitetura
5.  Auditoria funcional
6.  Auditoria de frontend
7.  Auditoria de backend
8.  Auditoria de banco de dados
9.  Auditoria de integrações
10. Auditoria de segurança
11. Auditoria de performance
12. Auditoria de testes
13. Auditoria de documentação existente
14. Consolidação da documentação
15. Geração do Dossiê Mãe

------------------------------------------------------------------------

# 4. Entregáveis obrigatórios

Gerar os seguintes arquivos:

-   `AUDITORIA_SISTEMA.md`
-   `MAPA_ARQUITETURA.md`
-   `HANDOFF_PROXIMA_SESSAO.md`
-   `DOSSIE_MAE_PROJETO.md`

------------------------------------------------------------------------

------------------------------------------------------------------------

# 6. Critérios de Qualidade

A auditoria somente será considerada concluída quando:

-   Todo arquivo importante estiver mapeado
-   Toda funcionalidade estiver documentada
-   Todos os riscos estiverem classificados
-   Todo o contexto necessário para continuidade estiver registrado
-   O Dossiê Mãe permitir que outra sessão assuma o projeto
    imediatamente

------------------------------------------------------------------------

# 7. Regra Final

A prioridade não é modificar o sistema.

A prioridade é produzir uma documentação definitiva, completa,
organizada e reutilizável, capaz de servir como fonte única de verdade
para continuidade do projeto em futuras sessões.
